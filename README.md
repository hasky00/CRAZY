# CRAZY — Critical Response Against Zero-day Yikes

> Every day is zero day. CRAZY is the bodyguard.

## Mission

CRAZY detects abnormalities and zero-day-style vulnerabilities across the five most used
programming languages, built for environments where a bad day costs real money: banking
and the wider finance sector.

## Target languages

1. Python
2. JavaScript / TypeScript
3. Java
4. C / C++
5. Go

## Core ideas

- Continuous, not one-off: scan every day, because every day is zero day.
- Anomaly-first: flag code and runtime behaviour that looks wrong, even when no CVE exists yet.
- Finance-aware: extra weight on auth, payments, ledgers, secrets and data handling.
- Language-aware: memory-safety checks for C/C++, dependency and injection checks for the rest.
