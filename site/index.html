What it catches

  • Injection: SQL, shell, code (eval/pickle/deserialisation), XSS, XXE, JNDI (Log4Shell family)
  • Memory: strcpy/gets/sprintf, format strings, overflow-prone malloc
  • Crypto and TLS: disabled certificate checks, weak hashes, insecure random
  • Secrets: API keys, AWS keys, private keys committed in source
  • Finance pack: card numbers (PAN) and IBANs in code, money as float, sensitive data in logs, disabled auth/MFA/KYC flags, money-moving calls without idempotency
  • Dependencies: every declared package checked against osv.dev, used by Google and GitHub
